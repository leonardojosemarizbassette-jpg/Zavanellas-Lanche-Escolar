# Zavanellas-Lanche-Escolar
Oferecemos lanches escolares saudáveis e equilibrados, entregues diretamente nas escolas de segunda a sexta-feira. Todos os dias, as crianças recebem um combo completo com suco natural, porção de frutas e um lanche variado, como pão de queijo, bolinho, esfirra e outras opções.
